# WindowHotkey · 给窗口绑一组键，一键收起来、一键叫回来

把常用的窗口藏到快捷键后面：按一组键，它最小化；再按一次，它回到最前面。
不用点任务栏，不用在几十个窗口里翻。

**当前版本：v2.0.1** ｜ 仅支持 Windows 10 / 11 ｜ 单文件 exe，免安装、不联网

---

## 为什么做这个

浏览器一开就是二十个标签页，IDE、聊天工具、文档全挤在任务栏上。
想要的那个窗口总是藏在后面，鼠标点缩略图又慢又容易点错。

这个程序做的事情很小：一个窗口 ↔ 一组快捷键。
按下去它就消失，再按一下就回来，并且自动带到最前面。

程序本身不占任务栏、不出现在 Alt+Tab 里，平时只待在右下角托盘。

---

## 三步上手

1. **选窗口** — 第 1 步的下拉框里挑一个正在开的窗口（可以打字搜索标题或程序名）。
2. **录键** — 点第 2 步的录制区，直接按下你想要的组合键，比如 `Ctrl + Alt + Z`。
3. **绑定** — 点「绑定」。以后按这组键就能收放这个窗口。

## 功能

| | |
| --- | --- |
| 窗口显隐切换 | 窗口开着 → 最小化；已经最小化 → 还原并置顶 |
| 按程序绑定 | 绑定关系记的是 **程序名**，不是窗口句柄。浏览器、IDE 重启后照样能用 |
| 快速绑定 | 按一组全局键，自动把「当前正在用的那个窗口」填进录入区，只差按一组键 |
| 窗口置顶 | 另一组全局键，把最前面的窗口钉住 / 放开，并画一圈高亮边框 |
| 鼠标键 | 支持把鼠标左/右键做成组合键的一部分（录入方式见下） |
| 托盘常驻 | 关掉窗口不退出程序；没有任务栏按钮、没有窗口缩略图、不进 Alt+Tab |
| 开机自启 | 写 `HKCU\...\Run` 注册表项，登录后静默进托盘 |
| 深色 / 浅色 | 右上角一键切换，选择会记住 |
| 界面动效开关 | 默认开；关掉后所有位移和淡入压到几十毫秒内，只留状态反馈 |
| 单实例 | 再点一次快捷方式不会多开一个，只会把已经开着的那个叫到前面 |
| 自动保存 | 任何改动立刻落盘，下次打开还是原样 |

### 默认的全局键

| 用途 | 默认 | 说明 |
| --- | --- | --- |
| 快速绑定 | `Ctrl + Alt + B` | 在左侧栏「快速绑定当前窗口」那行可以直接改 |
| 窗口置顶 | `Ctrl + Alt + P` | 同上，在「窗口置顶开关」那行改 |

改这两组键的交互和绑定普通窗口一样：进入录制状态 → 按新组合键 → 自动生效。

### 鼠标键怎么录

键盘录制区里没法真的点鼠标，所以用两个键当替身：

```
[  →  鼠标左键
]  →  鼠标右键
```

先按 `[`，再按一个字母键，就录成了「鼠标左键 + 那个字母」。
例如 `[` 然后 `Q`，之后按住鼠标左键再敲 Q 就能收放这个窗口。

## 界面

窗口 964 × 660，无边框，拖动顶部区域即可移动。

**左侧深色栏**
- 顶部是产品名和版本号
- 中间那块「键帽舞台」显示当前选中 / 最近一次触发的组合键，触发时键帽会真的按下去
- 下面依次是：绑定数量、快速绑定、窗口置顶、开机自启、界面动效
- 底部两个按钮：收进托盘、退出

**右侧工作区**
- 第 1 步·选窗口：带搜索的窗口选择器，只显示任务栏上的真实窗口，带程序图标
- 第 2 步·录快捷键：录制区，未录到修饰键时会原地抖一下并提示
- 下面是绑定列表，每行显示组合键、窗口标题、程序名和状态（已就绪 / 窗口没开）
- 鼠标悬停某一行会浮起来，右侧出现两个按钮：**立刻切换一次** 和 **解除绑定**
- 列表底部「全部解除」清空所有绑定

**动效**
入场是分层错峰进入（侧栏 → 录入区 → 列表逐行），不是整块淡入；
触发快捷键时键帽有按下位移，右下角同时出一条提示；
出错用水平抖动，不用弹窗。所有位移都伴随透明度或尺寸变化，不会只靠淡入表达状态。

## 文件放在哪

| | |
| --- | --- |
| 配置 | `%APPDATA%\WindowHotkey\config.json` |
| 崩溃日志 | `%APPDATA%\WindowHotkey\crash.log`（只在真的抛异常时才生成） |

配置长这样：

```json
{
  "appearance": "light",
  "motion": true,
  "autostart": true,
  "quick_bind_hotkey": { "mod_flags": 6, "vk": 66, "display": "Ctrl + Alt + B" },
  "pin_hotkey": { "mod_flags": 6, "vk": 80, "display": "Ctrl + Alt + P" },
  "bindings": [
    {
      "exe": "Code.exe",
      "title": "window_hotkey.py - Visual Studio Code",
      "mod_flags": 6,
      "vk": 90,
      "mouse_btn": 0,
      "display": "Ctrl + Alt + Z",
      "path": "D:\\Microsoft VS Code\\Code.exe"
    }
  ]
}
```

`mod_flags` 是 Windows 注册全局热键的修饰键位掩码（Alt=1 / Ctrl=2 / Shift=4 / Win=8），
`vk` 是虚拟键码，`mouse_btn` 为 1/2 表示鼠标左/右键。

## 拿可执行文件

仓库里不放 `WindowHotkey.exe`：它有 41 MB，超过 GitHub 的 25 MB 单文件上限，也无法用文件 API 上传。
要拿到 exe，自己打一份（见下面「自己打包成 exe」），或者在 Issues 里说明你的 Windows 版本，
由维护者手动挂到 Release 附件上（附件上限 2 GB）。

打包出来的 exe 免安装、不联网，放到任意目录双击即可运行。

仓库里也没有 `icon.ico`（同样是二进制）。想让 exe 带自己的图标，
把一个 `.ico` 放到项目根目录并命名为 `icon.ico` 再打包；缺了它 `build_exe.bat` 会跳过图标，用 Windows 默认图标。

## 从源码运行

```bash
python -m pip install -r requirements.txt
python window_hotkey_qt.py
```

## 自己打包成 exe

双击 `build_exe.bat`，或者手动执行：

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name WindowHotkey --icon icon.ico --add-data "icon.ico;." ^
  window_hotkey_qt.py
```

产物在 `dist\WindowHotkey.exe`。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `window_hotkey_qt.py` | 界面与交互：侧栏、键帽舞台、窗口选择器、录制区、绑定列表、托盘、单实例 |
| `whk_design.py` | 设计系统与动效原语：色板、字阶、键帽绘制、图标、补间/淡入/抖动/悬浮等 |
| `hotkey_engine.py` | 与界面无关的一层：`RegisterHotKey`、鼠标键轮询、窗口枚举与显隐、配置读写、事件队列 |

热键在独立线程里监听，界面只从事件队列取通知，所以按快捷键不会卡住渲染。

**依赖**：PyQt6、pywin32。没有别的。

## 注意事项

- 要控制**以管理员身份运行**的程序，本程序也得用管理员身份运行，否则那组键按了没反应。
- 同一个程序只能绑一组键，重复绑定会提示「这个程序已经绑过了」。
- 组合键注册失败，通常是已经被别的程序占用，换一组即可。
- 一个组合键里必须至少有一个修饰键（Ctrl / Alt / Shift / Win），单按一个字母不会被采纳。
- 绑定列表里的「窗口没开」不是错误：程序没在跑，等它开起来按原键照样生效。
- 只支持 Windows。用的是 `RegisterHotKey` + DWM/Win32 窗口操作，没有跨平台层。
